# 低速閉鎖・保持の計測（旧方式の記録）

現在の目的では摩擦保持を成功条件に使わない。
[幾何学的閉鎖の評価](../artifacts/geometric-closure/README.md)へ移行した。
以下の計測・停止ルールは、以前の実験を再現するための履歴として残す。

対象は、布との非交差と有限把持面の条件を通った436配置（29足首姿勢）。
候補のないNo.9、32、24を含め、全32姿勢を集計表へ載せる。
足首ごとに静定した初期状態を作り直し、各配置を独立したPlayerで1回ずつ試行する。
再選別前の候補や、別配置の試行後に変形した布は初期状態に使わない。

## 試験装置とプロトコル

右手の5個の実衝突メッシュ（両指、両指付け根、手のひら）を、キネマティックな
RigidbodyとObiColliderを持つ検査用治具として候補位置へ配置する。
腕のIK・モーター制御・実機トルク制限を再現するものではない。
布への把持拘束・粒子の固定追加は行わない。
足の皮膚形状、つま先の支持、開口部30mm帯の接触マスクと縮約尾部モデルは維持する。

| 項目 | 設定 |
| --- | --- |
| 物理ステップ | 20ms |
| 時系列出力 | 100msごと。接触・速度はその区間内の物理ステップから集計 |
| 治具配置後の静止 | 0.5秒 |
| 閉鎖速度 | 指間の開き幅として5mm/s、片指あたり2.5mm/s |
| 暫定の閉鎖停止 | 正の接触ソルバー値が両指に同じ物理ステップで発生し、直近5ステップ連続したことを閉鎖フェーズで確認 |
| 正の接触の検出閾値 | raw `normalImpulse` の絶対値が1e-8超 |
| 閉鎖の下限 | 幾何学的な開き幅0mm |
| 閉鎖後の保持 | 2秒 |
| 引き試験 | 接近方向の逆へ1秒かけて5mm移動 |
| 引き後の保持 | 1秒 |
| 安全停止 | 指・手のひらと足皮膚、または左右の指同士に10µmを超える幾何的侵入が検出された場合 |

停止ルールは計測のための暫定ルールで、把持成功条件ではない。
静止中の接触履歴も直近5ステップへ含む。接触が安定していれば、閉鎖開始直後に停止する場合もある。
閉じ幅は治具へ与えた幾何学的な指令値であり、実機エンコーダー値ではない。
0mmまで進んでも両側接触停止条件に到達しない場合は、別の停止理由として記録する。
安全停止は初期配置の1mm余裕とは異なり、侵入の有無に基づく。

## 記録値

各 `pose-XX/candidate-NNN.json` に選別元の候補、初期状態、指の始終端姿勢、プロトコル、
初期化検査、時系列、終了状態を保存する。

- 時刻、閉鎖・静止保持・引き・引き後保持のフェーズ、開き幅、引き量、TCP位置。
- 両指・指付け根・手のひらの5部品別の近接イベント数、正の接触イベント数、
  正の接触が発生した物理ステップ数、接触単体を構成する布粒子ID。
- 両指が**同じ物理ステップ**で正の接触を持ったステップ数。100ms内に片指ずつ交互に接触しただけの状態と区別する。
- raw `normalImpulse` と接線・従接線成分から得た摩擦ソルバー値の区間合計、接触距離の最小値。
- 最初の同時接触の開き幅、閉鎖停止理由・停止開き幅、安全停止時の部品・侵入量。
- 狙った布の**同じ材料点**の位置。元の三角形と固定した重心座標で追跡する。
- 開口部帯の全96粒子の位置と区間内の最大速度。帯外の接触数。
- 終了時の全布頂点、エッジ伸び率の最大値・95パーセンタイル。
- 粒子半径、治具のObi厚み、帯の逆質量、布の静・動摩擦係数、治具の摩擦材設定の有無。

ソルバーの `normalImpulse` というフィールド名をそのまま記録しているが、
Newtonや実機の把持力へ変換する校正はしていない。N単位の力やモーター電流は報告しない。
治具の摩擦材がnullの場合、このバックエンドは布側の衝突摩擦材を使う。

## 捕捉・滑りの指標

接触しているだけで捕捉成功とはしない。保持フェーズでは次を別々に集計する。

- 同時接触の継続率：同時接触した物理ステップ数 / 観測した物理ステップ数。
- 材料点が有限把持面内に残る割合：TCPを中心とする8×8mm窓と実指断面の間に、
  追跡した材料点があるかを時系列で判定する。
- 把持面付近の布の幾何学的な近接：8×8mm窓の5×5本の直線と実際の布三角形・指断面を交差させ、
  両対向面の有効接触包絡内に布があるかを調べる。力を直接局在化したセンサー値ではない。
- 狙った材料点のTCPに対する最大移動量。布が世界座標で静止し、治具だけが5mm移動すれば、
  この値は約5mmとなるので保持成功と区別できる。
- 接触単体の同じ支持粒子が、治具の接線方向へどれだけ移動したか。左右別に、
  3観測区間以上で追跡できた粒子の最大値・中央値を保存する。

これらは材料点・接触単体支持粒子の相対移動指標であり、接触界面での厳密な滑りの実測値ではない。
捕捉の成立が確認できないものを「滑り0mm」とはしない。評価できない値はnull/CSVの空欄にする。
つま先支持を残すため、自重を全てグリッパーだけで保持したという主張もしない。

暫定評価値は、同時接触と把持面内残留がそれぞれ80%以上、材料点と接触支持粒子の接線移動が各3mm以下、
最後の0.5秒の帯速度が0.05m/s以下とした。帯外接触・安全停止・非数値は失敗条件。
局所把持面付近の近接も評価する。これらを通過しても `provisional_retention_proxy` とし、
物理的な把持・保持成功の検証済みフラグは付けない。
各配置1試行の記録であり、試行間ばらつきや実機に適用する閾値は未校正。

## 実行と出力

```bash
SOCK_BUILD_LOG_DIR=/tmp/sock-closure-v5-build \
  ./scripts/build_custom_player.sh development Build/SockDressingPlayer/ClosureMeasureV5
PYTHONPATH=/tmp/sock-grasp-deps:/opt/ros/noetic/lib/python3/dist-packages \
  python3 scripts/measure_grasp_closure.py --workers 16
PYTHONPATH=/tmp/sock-grasp-deps python3 scripts/report_grasp_closure.py
```

`scripts/run_closure_player.sh` はPlayerのジョブスレッド数を2に制限し、条件ごとにログを保存する。
`SOCK_CLOSURE_OUTPUT` で実験出力先を分離できる。途中から再実行した場合、V5の保存済み条件を再計測しない。
試行のエラーは条件別に記録し、未完了は成功件数へ含めない。

- `artifacts/grasp-closure-measurements/measurement-report.json`：32姿勢の網羅状況と暫定判定の集計。
- `measurements.csv`：全配置の主要測定値。`pending` や `measurement_error` があれば未完了。
- `poses.csv`：候補のない姿勢も含む足首角度別の件数。
- `pose-XX/candidate-NNN.json`：各条件の生時系列と元の配置情報。

## 計測治具の登録不具合への対応

初期試行で、Obiの登録待ちハンドルへ `UpdateIfNeeded()` を呼ぶ順序の不具合を検出した。
負のインデックスでネイティブ配列を更新し得るため、登録バッファを確定してから更新するよう修正した。
初期化側にも同じ順序を適用し、ObiColliderBaseにも無効ハンドルを拒否するガードを追加した。
初期試行のV1–V4は最終データへ混ぜない。最終対象はV5で取り直したデータだけとする。

## 判定閾値の調整

`config/grasp_closure_decision.yaml` に後処理の閾値をまとめた。
`report_grasp_closure.py --criteria <設定ファイル>` で、保存済みの生データから再評価できる。
これは保持判定の閾値を変える操作で、計測時の閉鎖停止タイミングは変わらない。
閉鎖速度・停止ルール・保持動作を変える実験は、`SOCK_CLOSURE_OUTPUT` で別の出力先に分けて実施する。

集計JSONには、材料点・接触支持粒子の移動量閾値1/2/3/5/10mmと同時接触率50/80/90%を
組み合わせた後処理の感度表も保存する。他の条件は固定し、物理試行は再実行しない。
`failed_gates_nonexclusive` は複数の不合格条件を重複して数えるので、合計は試行数と一致しない。
`status_counts` は優先順で一つに分類した件数。

CSVの `pull_follow_ratio` は、引き動作直前の最後の保持観測から、引き後の最後の観測までの
材料点の引き方向への移動量を、治具の移動量で割った値。0なら布が世界座標でほぼ静止、
1なら引き方向へ同じ量だけ追従したことを示す。1でも他方向のずれや捕捉成立を保証しない。
材料点の接線方向の移動量と速度も、100msサンプリングから計算してCSVへ保存する。

`validate_closure_dataset.py` は、初期TCPと追跡材料点の一致、同時接触カウンター、
物理ステップと観測時間の対応、TCPと引き量の対応、最後の観測と終了頂点位置の一致を検査する。
```
python3 scripts/validate_closure_dataset.py
```

別出力先の負の対照試験では、足へ30mm侵入する配置にして、布の物理時間を進める前の安全停止を確認した。
材料点の移動量・保持接触率はnullで、布の変位は0mだった。
`artifacts/grasp-closure-negative-control/control-checks.json` に結果を保存し、436配置の集計からは除外する。

足とグリッパーの剛体接触はBakeした実皮膚だが、布と足の内部接触補正は既存の凸包モデルである。
これは初期状態を維持するための現在のモデル条件であり、実皮膚による布接触へ置き換えた場合の把持性能は検証していない。
判定値の変更だけで捕捉成立を主張せず、この接触モデルの影響も必要に応じて切り分ける。

## V5の全件計測結果

29姿勢・436配置すべての生時系列を記録した。3姿勢は選別候補なしとして姿勢別表に記載。
397配置で暫定の両側接触停止が成立し、39配置は停止条件に達せず0mmの開き幅下限へ到達した。
足・指同士への侵入による安全停止は0件、最終計測の実行エラーは0件。
暫定保持判定をすべて通過した配置は0件だった。

保持中の同時接触率の中央値は34.2%、材料点相対移動量の中央値は6.65mm、
引き追従率の中央値は0.00235（約0.23%）だった。
後処理で接触率を50/80/90%、移動量閾値を1/2/3/5/10mmへ変えても、
他の条件を固定した暫定保持判定の通過件数は0件だった。
この結果は現在の停止ルールとモデルの下での評価であり、実機把持の不可能性を示すものではない。

閉鎖停止に使う接触は指全体の接触なので、局所把持面で布を捕捉したことを保証していない。
次の比較では、目標把持面内の両側接触を閉鎖停止に結び付ける条件と、
引き動作に対する同じ材料領域の追従を確認する必要がある。
布と足の既存凸包補正の影響と、接触時の大きな速度・伸びの妥当性も切り分けが必要。

全436件のデータ整合性検査が通過し、初期TCPと追跡材料点の誤差は0mだった。
全436件が再選別元の入力と一致することも確認した。関連自動テスト107件が通過した。
