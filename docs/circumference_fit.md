# 外周を縮めて足に保持させる初期化

`config/preinsert_fitted.yaml` は、以前の大きな幾何学的配置を準備形状として使い、
外周の自然長を段階的に縮めてから通常重力で保持を検証する設定です。
ロボットの把持や、粒子の固定、ワールド座標への追従拘束は使いません。

## 実行

```bash
python3 -m pip install -e '.[fit,test]'
SOCK_BUILD_LOG_DIR=/tmp/sock-fit-unity-logs \
  ./scripts/build_custom_player.sh development Build/SockDressingPlayer/CircumferenceFitV5
python3 scripts/fit_preinsert.py --stage A
```

`--stage B`〜`--stage E` で開口位置を変えられます。`--headless` は画像を作らず物理検証と
状態保存だけを行います。各結果は `artifacts/sock-pose-pattern/preinsert-fitted/<段階>/` に保存します。

- `contraction-overview.jpg`: 同じカメラ位置での縮小過程と保持後の画像。
- `report.json`: 自然外周倍率、実際の開口外周、張力、保持検査、交差検査。
- `telemetry.jsonl`: 縮小と重力保持中の時系列。
- `runtime-config.yaml`: 実行時の設定。
- `initial-prepared-state.json`: 縮小前のモデル基準となる配置。
- `fitted-prepared-state.json`: 縮小・保持後の粒子位置、速度、材料自然長。
- `foot-collision-hull.json`: 現在の姿勢の足表面を覆う接触形状とnativeによる被覆確認。
- `fitted-geometry.json`: 独立した面交差検査に使用できる粒子・辺・面・自然長。

保持試験が失敗した結果は `passed: false` として保存し、コマンドは終了コード2を返します。
その状態を検証済み初期状態として読み込むことはできません。

## 何を縮めるか

最初に大きな配置を無張力の基準形状として材料に設定します。そこから各リングの
中心線を変えず、周方向の材料寸法を1%ずつ小さくします。軸方向の自然寸法を一括して
短くする処理ではありません。粒子を縮小後の位置に直接移動させず、Obiの距離制約が
持つ自然長を変更して、実際の物理ステップで形を変えます。

整形中だけ重力をゼロにして、張力が足へ伝わる形に落ち着かせます。その後は通常重力
`[0, -9.81, 0] m/s²` に戻し、既定で500ステップ（10秒間）の保持を行います。
靴下の質量は50 gで、801粒子すべてが有限質量を持ちます。

張力はnative距離制約の乗数をサブステップ時間の二乗で割って得たモデル上の力です。
開口辺の中央値が既定の0.08 Nに達したところで縮小を止めます。
0.01〜0.5 Nを保持時の張力範囲としています。これは実物の素材を実測して校正した値ではありません。

## 接触と保持の条件

足とすねの接触形状は、その時点のスキンメッシュと隣接面からそれぞれ凸包を作ります。
古い姿勢の固定形状を流用せず、native側で全支持頂点が覆われていることを確認します。
足との法線方向の侵入を補正し、布の張力による押し付け力に応じてCoulomb摩擦の上限を
適用します。布同士は有限半径の粒子で自己接触させます。足・すねとの隙間は2.5 mm、自己接触のサンプリング半径は7 mmと別々に設定しています。
この設定ではロボット・椅子・床による支えを無効にし、別の物体に支えられている状態を成功に含めません。
足・すねの法線接触と摩擦はサブステップごとの専用制約で解きます。ロボットによる引き上げには、接触の復帰と再把持が別途必要です。

最後の1秒間について、以下をすべて満たすことが必要です。

- 通常重力で実際に物理時計が進んでいる。
- 全粒子が有限質量で、把持・位置固定がない。
- 接触補正が各サブステップで実行されている。
- 足への接触が継続し、侵入量が1 mm以下。
- 開口中心の変動と、各開口粒子の位置変動が5 mm以下。
- 観測間隔から求めた各開口粒子の移動速度が5 cm/s以下。
- 開口が保持開始位置から2 cm以上離れていない。
- 開口の張力中央値が0.01〜0.5 N、周方向辺の最大張力が2 N以下。

さらに、最終形状を独立に検査し、足との辺・面交差と布の自己交差がないことを確認します。
粗い布メッシュの局所的な折れ方には実行間のばらつきがあり、保持に成功していても
自己交差が残った実行は採用しません。ライブラリからの初期化にも同じ検査を適用します。
布全体の瞬間的な最大速度もレポートに残します。保持の判定は足との接触部を対象としており、
つま先の先に余った自由部分が重力で垂れたり動いたりすることは許容しています。

## シミュレータの初期状態として使用する

`SockDressingEnv` を `config/preinsert_fitted.yaml` で作成すると、`apply_scenario()` の末尾で
物理フィットを実施します。保持検査に失敗した場合は開始を拒否します。

保存済みの検証済み状態は、次のコマンドで復元と保持の再検査を行えます。

```bash
python3 scripts/fit_preinsert.py \
  --restore artifacts/sock-pose-pattern/preinsert-fitted/A \
  --output /tmp/sock-fit-restored
```

ライブラリからは、保存時と同じ設定・足の姿勢でシーンを準備した後に
`restore_fit(environment, directory)` を使います。初期基準形状、縮小後の自然長、接触形状を
再構成してからnative状態を戻し、粒子位置の読み戻しも照合します。
足の姿勢や接触形状が違う場合には復元を拒否します。

ライブラリで保存状態を読み込む際は、シーン準備用設定から `circumference_fit` を外し、
自動フィットを実行しないでください。上記の復元コマンドはこの処理を自動で行います。

## 保存した検証結果

`artifacts/sock-pose-pattern/preinsert-fitted/` にA〜Eの通過状態と
`summary.json`を保存しています。各段階で10秒間の通常重力保持と最終交差検査を通過しました。
下表の移動量は、保持終了前1秒間の開口粒子の最大変位です。

|段階|縮小前の開口外周|保持後の開口外周|張力中央値|最大変位|
|---|---:|---:|---:|---:|
|A|44.7 cm|26.5 cm|0.078 N|0.014 mm|
|B|47.6 cm|29.8 cm|0.097 N|0.020 mm|
|C|50.4 cm|32.7 cm|0.100 N|0.045 mm|
|D|45.0 cm|31.3 cm|0.096 N|0.035 mm|
|E|42.0 cm|28.9 cm|0.089 N|0.001 mm|

Aには`contraction-overview.jpg`と`retention.png`もあります。

保存したAを別プロセスで復元した追加試験でも接触部の保持は通過しましたが、
2秒後の自由部分に自己交差2辺が生じ、最終形状検査は不通過でした。
保存時の形状検査通過は、後続の自由部分の自己交差を保証するものではありません。
