# 布との交差と有限の把持面による再選別

`grasp_cloth_geometry.ClothScreen` と `scripts/refilter_grasp_candidates.py` を追加した。
既存の探索は足との干渉だけによる一次候補を出す段階として残し、この処理を後段で実行する。
最終的な静的配置候補は `artifacts/grasp-cloth-refilter/pose-XX/report.json` の `accepted`。
以前の `artifacts/right-grasp-geometry/` の候補を把持可能な最終候補として使わない。

## 条件

1. 指・指の付け根・手のひらの5凸形状と、布全体の三角形との交差をFCLで検査し、交差する配置を除外する。
   帯以外の布との交差も除外する。布の粒子だけを調べる方式ではない。
2. TCPを中心に接近方向・指幅方向の8×8mm窓を設け、5×5点を検査する。
   各点で閉鎖方向の直線と両指の実凸形状を交差させ、有限な指形状に両方とも当たる場合だけ、対向面の位置を求める。
   その間に実際の布の三角形が存在し、各把持面から閉鎖軸方向に0.5mm以上離れている点を有効とする。
   四隅すべてが有効な2×2mmセルの面積合計が4mm²以上であることを要求する。
   一点だけ、線だけ、指幅の外側、指先の外側にある布では通らない。
3. 各開き幅で足との余裕1mmを再確認する。さらに50mmの直線接近の掃引体積について、足と布の非干渉を確認する。

窓寸法・面積・余裕は初期設定値であり、ユーザーが確定した実機パラメータではない。
`config/grasp_cloth_screen.yaml` で変更できる。実際の指断面より窓が広い部分は自動的に対象外になる。
把持面内の条件は有限グリッドによる判定で、窓内全点の連続的な包含や保持能力を証明しない。
閉鎖中は布の変形が必要になるため、固定した布に対して5mmまで無交差で閉じられるという条件は課していない。
合格時の開き幅は開いた状態の配置であり、閉鎖・接触・保持成功を意味しない。

## 結果

32姿勢の保存済み静定状態を使用し、以前に足の一次判定を通った10,790方向について、
開き幅5・10・20・30・40・50mmを再検査した（64,740配置）。
元の全方向グリッドを最初から再探索したものではない。以前の5mm時点の足判定で落ちた方向は探索範囲に含まれない。

| 結果 | 配置数 |
| --- | ---: |
| 足の条件で除外 | 38,968 |
| 指・手のひらと布の交差で除外 | 25,328 |
| 把持面内の面積条件で除外 | 8 |
| 静的配置と直線接近の条件を通過 | 436 |

436件は開き幅や左右の指の割り当てが異なる配置を別件として数えている。
29/32姿勢に候補が残った。候補なしはNo.9（pitch30°・roll5°）、No.32（30°・15°）、No.24（30°・30°）。
この結果は指定した探索範囲で候補がないことを示し、連続空間全体での把持不可能性を意味しない。

撮影済みのA・B・Cは布交差で除外し、D（開き50mm）は通過する回帰テストを追加した。
人工的な布による、把持面外・指に重なる布・小さすぎる布・縁・線だけの配置のテストも実施。
関連23テストが通過した。
